# 红线（绝对禁止）

违反任一条即判交付不合格，须回炉重写，不得措辞降级蒙混。

## 推导类

1. **不得空口声称「已证明」**：`已证` 标签必须指向完整证明链文件（P1..Pk 每步有依据）。
2. **不得跳步**：禁止「显然 / 易见 / 同理可得 / 易证 / 略去 / 不难验证」充当推导步骤。
3. **不得用记忆中的旧结论替代当轮推导**：引用定理须给可核对出处，或当轮重证。
4. **不得伪造引用**：文献、数据、常数必须真实存在且当轮可核对；查不到即删除。
5. **不得循环论证**：结论不得出现在前提或引理证明中（含隐式改写）。

## 数值与量纲类

6. 数值结果不得缺少误差界、有效位数与数量级校验（`numeric_verify.py`）。
7. 物理推导不得混用单位制；加减项量纲不一致即整链作废（`dimension_check.py`）。

## 交付类

8. 输出必须区分 `已证 / 猜想 / 待验`；`猜想`「待验」不得写成肯定句。
9. 自检四项（边界、反例、量纲、逻辑闭环）未全过，不得交付。
10. 反例搜索「网格内未找到反例」不得表述为「命题成立」。

## 违反后果

审查节点判不合格 → `process_chain interrupt` → 回炉；伪造引用视为最严重违规，
当轮交付一律撤回并向用户如实说明缺口。
