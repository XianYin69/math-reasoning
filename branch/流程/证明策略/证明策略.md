# 证明策略（Strategy）

显式选择证明方法并说明理由；未声明策略不得开写证明链。

## 策略清单

| 编号 | 策略 | 适用判据 | 主要风险 |
|---|---|---|---|
| S1 | 直接证明 | 目标由定义/已知定理单链可推出 | 隐含前提未列出 |
| S2 | 反证 | 结论否定与假设集不相容 | 排中律依赖（直觉主义逻辑失效） |
| S3 | 逆否 | 条件式结论、逆否更易推 | 量词取反出错 |
| S4 | 数学归纳 | 命题对自然数参数递归 | 归纳假设使用范围越界 |
| S5 | 强归纳/良基归纳 | 依赖多个前项或良基关系 | 良基性未证明 |
| S6 | 构造法 | 存在性命题需给出对象 | 构造不可计算/不适定 |
| S7 | 计数论证 | 双计数、抽屉原理 | 计数重复或遗漏 |
| S8 | 极值原理 | 有限集/紧集上取最值 | 存在性前提缺失 |
| S9 | 概率法 | 证存在性：随机对象以正概率满足 | 独立性假设不成立 |

## 步骤

1. 依目标命题形态（全称/存在/不等式/等式/结构对应）选 1–2 个候选策略。
2. 写出选择理由与被弃策略的弃用原因（各一句）。
3. 列出所需引理清单 `L1..Lk`，标注每条引理的来源：当轮证明 / 已知定理（须可核对）。
4. 逻辑链留痕：`证明策略 → 证明链`，理由＝策略与命题形态匹配且引理清单闭合。

## 禁止

- 策略混用不声明（如归纳中偷偷用反证而不标注）。
- 引理来源写「众所周知」而无出处或当轮证明。
