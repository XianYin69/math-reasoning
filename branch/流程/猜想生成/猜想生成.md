# 猜想生成（Conjecture）

由特例到候选命题的五段式：特例 → 模式 → 猜想 → 类比推广 → 反例排查。

## 步骤

1. **特例表**：取 3–5 个可手算的特例（含最小情形、退化情形、极端参数），列成表。
2. **模式识别**：写出观察到的规律（单调性、上/下界形式、不变量、递推、对称）。
3. **猜想陈述**：写成带量词与等号/不等号方向的命题 `C1`，标明**成立条件**与**失败边界**。
4. **类比推广**：换结构（数→多项式→算子；有限→可数；欧氏→度量空间）看规律是否存活。
5. **反例排查**：`python scripts/counterexample_search.py --spec <命题文件>` 在参数网格上
   搜反例；命中反例即降级为 `待验` 并记录最小反例。

## 候选命题记录格式

```
C1：陈述（含量词、条件）
  支持证据：特例编号 E1..En；类比 A1
  成立条件：…
  失败边界：…（参数越界/结构缺失时如何失效）
  状态：猜想（未证）
```

## 禁止

- 把「特例成立」写成「已证明」；猜想不标成立条件。
- 未做反例排查就交付候选命题。
