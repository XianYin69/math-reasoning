# 交付分级（Deliver）

按证据强度给结论打标签，输出三段式：结论 / 依据 / 缺口。

## 三级标签

| 标签 | 含义 | 允许措辞 | 禁止措辞 |
|---|---|---|---|
| `已证` | 证明链四项自检全过 | 「证明如下」「证毕」 | 「应该」「大概」 |
| `猜想` | 有特例/模式支持，无证明链 | 「猜想：… 成立条件…」 | 「已证明」 |
| `待验` | 存在缺口或反例未排除 | 「待验证，缺口为…」 | 「成立」 |

## 交付模板

```
【结论】G1：<陈述>            标签：已证 / 猜想 / 待验
【依据】P1..Pk（关键三步摘要）+ 引理 L1..Lk + 前提 H1..Hn 使用情况
【范围】成立条件：… ；失效情形：…
【数值】值：… ｜ 误差：±… ｜ 有效位数：n ｜ 数量级校验：一致/不一致
【缺口】（仅 猜想/待验 时必填）：还差什么才能升级为 已证
```

## 步骤

1. 汇总前六步产出，按模板填写。
2. 逐条核对标签与证据强度是否匹配（`已证` 必须能指向完整证明链文件）。
3. 物理侧附加：量纲结论、守恒律核对、估算与精确解互校结果一并列出。
4. 过程链存档：`process_chain.py save --step 交付分级`。
