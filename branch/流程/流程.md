# 流程（Process）

主干七步，串行执行；任一步自检不过即回炉上一步，不得跳步交付。

```
形式化 → 建模求解 → 猜想生成 → 证明策略 → 证明链 → 自检回炉 → 交付分级
```

| 步骤 | 路径 | 产出 |
|---|---|---|
| 形式化 | [形式化/](形式化/形式化.md) | 问题规格（对象/假设/记号/目标命题） |
| 建模求解 | [建模求解/](建模求解/建模求解.md) | 模型 + 求解路径 + 数值可信度 |
| 猜想生成 | [猜想生成/](猜想生成/猜想生成.md) | 候选命题（成立条件 + 失败边界） |
| 证明策略 | [证明策略/](证明策略/证明策略.md) | 策略选择与理由（九种之一或组合） |
| 证明链 | [证明链/](证明链/证明链.md) | 严格步骤链 + 引理拆解 + 前提使用清单 |
| 自检回炉 | [自检回炉/](自检回炉/自检回炉.md) | 四项自检结果；不过则回炉 |
| 交付分级 | [交付分级/](交付分级/交付分级.md) | `已证/猜想/待验` 标签化交付 |

## 机制挂载

- 逻辑链：每步决策 `logic_chain` 留痕（缓存落用户缓存目录，不入 skill 目录）。
- 过程链：每步 `process_chain save`，审查失败 `interrupt` → 修复 → `resume`。
- 惩罚：同一步重试达 10 次熔断，回退或求助用户。
