# 建模求解（Model & Solve）

在形式化规格之上选择数学/物理模型并求解；模型必须声明适用域。

## 步骤

1. **选模型**：列出候选模型与判据（线性/非线性、离散/连续、确定/随机）。
2. **映射检查**：确认原问题对象在模型中都有对应；无对应即降级为特例处理。
3. **求解路径**：解析解优先；不可得时给数值方案（算法、步长、截断、迭代终止条件）。
4. **数值可信度**：结果附误差界、有效位数、数量级校验（`scripts/numeric_verify.py`）。
5. **物理侧附加**：量纲一致性（`scripts/dimension_check.py`）、极限与特例验证、
   对称性与守恒律检查——见 [物理推理](../../../物理推理/SKILL.md)。
6. 逻辑链留痕：`建模求解 → 猜想生成`，理由＝模型适用域已声明且解可复核。

## 产出格式

```
模型：<名称> ｜ 适用域：<条件> ｜ 依据：<假设编号>
解：<表达式/数值> ｜ 误差：<±值 或 相对界> ｜ 有效位数：<n>
数量级校验：<估算阶 vs 计算阶，是否一致>
```

## 禁止

- 数值结果不给误差与位数；单位混用（SI 与非 SI 混算）。
- 模型适用域之外的外推被写成结论。
