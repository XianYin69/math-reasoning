# 证明链（Proof Chain）

把策略展开为逐步可追溯的证明链，每步一行、每行有依据。

## 步骤格式（每步一行）

```
P1  陈述：…                       依据：定义D / 假设H1 / 引理L1 / 定理T(出处) / P0
P2  陈述：…                       依据：P1 + H2（须写明用了哪部分）
…
Pk  陈述：= 目标命题 G1            依据：P(k-1)
```

## 硬性要求

1. **引理拆解**：每条引理单独成块，给陈述 + 证明（或可核对出处）。
2. **前提使用清单**：结尾列 `H1…Hn` 各自被哪些步骤使用；未使用的前提须说明是否可去掉。
3. **结论与适用范围**：写明结论成立的条件集合与失效情形。
4. **禁止跳步**：不得出现「显然」「易见」「同理可得」「略」；跨步推导须补中间步骤。
5. 校验：`python scripts/proof_chain_check.py --proof <证明文件>`（查依据缺失、跳步词、
   未使用前提、结论未闭合）。

## 产出

- 证明链文件（模板见 [证明链模板](../../../asset/证明链模板.md)）
- 校验输出（0 缺陷方可进入自检回炉）
