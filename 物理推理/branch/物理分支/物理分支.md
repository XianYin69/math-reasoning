# 物理分支（Physics Branches）

物理侧每道结论须过四关：量纲 → 极限特例 → 对称守恒 → 估算互校。

## 四关细则

| 关 | 检查 | 工具/判据 | 不过的处理 |
|---|---|---|---|
| 1 量纲分析 | 各加项同量纲；等式两边量纲一致；导出量用基本量表示 | `scripts/dimension_check.py`（幂次矩阵秩 → π 乘子数） | 回 [建模求解](../../branch/流程/建模求解/建模求解.md) 重列变量 |
| 2 极限与特例 | 参数取 0、∞、无相互作用、经典/相对论极限下行为 | 手算 + `numeric_verify.py` | 标注失效边界，结论降级 `待验` |
| 3 对称与守恒 | 平移/旋转/时间反演/规范对称 → 守恒量；破缺项须显式 | 诺特对应表（见下） | 补回缺失守恒项或修正模型 |
| 4 估算互校 | 数量级估算与精确解对比，偏差 >1 个数量级须解释 | `numeric_verify.py --estimate` | 重查单位换算与截断误差 |

## 对称 ↔ 守恒 对照

| 对称 | 守恒量 |
|---|---|
| 时间平移 | 能量 |
| 空间平移 | 动量 |
| 空间旋转 | 角动量 |
| 规范 U(1) | 电荷 |
| 洛伦兹不变 | 四动量、不变质量 |

## 模型假设与适用域（必写）

```
假设：A1 质点 / A2 无摩擦 / A3 非相对论(v≪c) / A4 连续介质 …
适用域：v/c < 10⁻² ；Knudsen 数 < 0.01 ；线性响应区 …
外推禁止：超出适用域的结论不得写成「已证」，只能标「待验 + 缺口」
```
