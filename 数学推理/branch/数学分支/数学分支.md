# 数学分支（Math Branches）

按领域给出「典型对象 / 起手策略 / 高频引理 / 失效边界」，选分支时先对齐对象类型。

| 分支 | 典型对象 | 起手策略 | 高频引理/工具 | 失效边界 |
|---|---|---|---|---|
| 数论 | 整数、同余、素数 | 构造 / 无穷递降 | 欧几里得除法、CRT、升阶 | 素数条件缺失时结论一般不成立 |
| 代数 | 群环域、模、多项式 | 同态像 / 商结构 | 同态基本定理、极大理想 | 非交换时中心论证失效 |
| 分析 | 级数、积分、算子 | 估计 + 夹逼 / 完备性 | MCT/DCT、Banach、Arzelà | 一致收敛前提缺失即断链 |
| 组合 | 图、计数、极值 | 双计数 / 抽屉 / 概率法 | 容斥、Ramsey、Lovász 局部引理 | 概率法需正概率，独立性须核验 |
| 几何/拓扑 | 度量空间、流形 | 不变量 / 极值原理 | 紧性、连通性、Borsuk | 非紧集上最值可能不存在 |
| 逻辑/集合 | 命题、序数、基数 | 反证 / 良基归纳 | 排中、选择公理依赖标注 | 直觉主义逻辑下 S2 不可用 |

## 使用规则

1. 先判定分支，再在 [证明策略](../../../branch/流程/证明策略/证明策略.md) 中选 S1–S9。
2. 跨分支迁移结论时，必须重验前提（例：有限集性质迁到紧集须重证紧性）。
3. 每条引理标注来源：当轮证明，或可核对的标准定理（禁止「众所周知」）。
