# resistance（数学推理约束库）

数学侧不可逾越的约束；与本体 [红线](../../resistance/红线/红线.md) 叠加生效，冲突时从严。

## 约束

1. **公理体系显式**：存在性命题须写明在何公理体系下（ZFC / 直觉主义 / 构造主义）；
   依赖选择公理、排中律的结论必须标注。
2. **不得空口已证**：`已证` 标签必须能指向完整证明链文件（P1..Pk 每步有依据）。
3. **量词不可漂移**：∀/∃ 顺序改变即不同命题；交换求和/极限须给条件（一致收敛、可积控制）。
4. **边界必查**：n=0/1、空集、退化参数、分母为零、区间端点逐项代入。
5. **反例优先**：升级 `猜想 → 已证` 前须至少一次主动反例尝试并记录结果。
6. **旧结论替代禁止**：不得用记忆中的定理名替代当轮推导；引用须可核对且真实存在。

## 违反后果

- 结论不可复现、审查节点判不合格、交付被回炉；伪造引用视为最严重违规（不可交付）。
