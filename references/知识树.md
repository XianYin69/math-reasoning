# 知识树（Knowledge Tree）

拓扑到当前不可再分：叶子节点均对应一条可执行校验或一类可选题策略。

```
数理推理
├── 形式化        → 对象/假设/记号/目标 → formalize_check.py
├── 建模求解
│   ├── 数学建模  → 离散/连续/代数/几何/概率
│   └── 物理建模  → 变量清单 → dimension_check.py → numeric_verify.py
├── 猜想生成      → 特例 → 模式 → 猜想 → 类比 → 反例排查(counterexample_search.py)
├── 证明策略      → S1–S9（见 证明方法目录.md）
├── 证明链        → 步骤/依据/引理/前提清单/结论 → proof_chain_check.py
├── 自检回炉      → 边界 · 反例 · 量纲 · 逻辑闭环
└── 交付分级      → 已证 / 猜想 / 待验
    ├── 数学推理（子技能）→ 数论 · 代数 · 分析 · 组合 · 几何拓扑 · 逻辑集合
    └── 物理推理（子技能）→ 量纲 · 极限特例 · 对称守恒 · 估算互校 · 适用域
```

## 再拓扑判据（何时还能继续拆）

- 某叶子没有对应校验或策略选项 → 继续拆；
- 某分支出现两类以上互斥判据 → 继续拆；
- 当前所有叶子均已绑定脚本/策略/标签 → **不可再拓扑**，知识库构建结束。
