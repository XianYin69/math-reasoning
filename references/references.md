# references（知识库索引）

本目录存放方法学知识与**当轮可核对**的外部来源；禁止写入未经核实的引用。

- [知识树](知识树.md)：领域拓扑（本体 → 子技能 → 分支 → 方法 → 校验）。
- [证明方法目录](证明方法目录.md)：S1–S9 策略的适用判据与失效边界。
- [量纲分析与π定理](量纲分析与π定理.md)：Buckingham π 的操作步骤与来源。
- [猜想生成与反例排查](猜想生成与反例排查.md)：自动化推理与反例搜索的文献锚点。
- [经验查询记录](经验查询记录.md)：本轮联网查询的**真实**结果（含失败来源）。

## 使用规则

1. 外部来源只作方法学锚点，**不得**当作具体命题的证明依据；
   具体定理须在当轮给出证明或可核对出处（见 [红线](../resistance/红线/红线.md)）。
2. 每条引用必须带可访问链接与访问日期；无法核实即删除。
3. 新增知识须能挂到 [知识树](知识树.md) 的某个节点，否则不入库。
