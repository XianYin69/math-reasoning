# 证明方法目录（S1–S9）

策略编号与 [证明策略](../branch/流程/证明策略/证明策略.md) 一致；此处只记判据与陷阱。

| 编号 | 策略 | 起手式 | 典型陷阱 |
|---|---|---|---|
| S1 | 直接证明 | 展开定义，逐条代入 | 隐含使用未声明前提 |
| S2 | 反证 | 设 ¬G1，导出与 H 集矛盾 | 依赖排中律；构造性数学中不可用 |
| S3 | 逆否 | 证 ¬结论 → ¬条件 | 量词取反漏写（∀↔∃） |
| S4 | 数学归纳 | 验证 n=1，k→k+1 | 归纳假设用错范围（用了 k+1 的结论） |
| S5 | 强归纳/良基归纳 | 设对所有 <n 成立 | 良基关系未证明（可无穷下降） |
| S6 | 构造法 | 显式给出对象并验证 | 构造依赖选择公理未标注 |
| S7 | 计数论证 | 双计数 / 抽屉原理 | 重复计数或漏计边界元 |
| S8 | 极值原理 | 取最小反例 / 最值点 | 最值存在性前提缺失（非紧集） |
| S9 | 概率法 | 证 P(满足)>0 | 独立性假设未核验 |

## 选择流程

1. 目标形态判定：全称 → S1/S3/S4；存在 → S6/S8/S9；不等式 → S1/S7/S8；等价 → S1 双向。
2. 选 1–2 个候选，各写一句「为何选它 / 为何弃另一」。
3. 若两条链都写出且互相依赖，须合并编号避免循环引用。
