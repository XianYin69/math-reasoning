# 量纲分析与 π 定理（物理侧方法锚点）

## 操作步骤

1. 列出问题中全部物理量（含待求量），写 `q1..qn`。
2. 写出每个量对基本量（M,L,T,Θ,I,N）的幂次向量。
3. 量纲矩阵秩 r → 独立无量纲乘子个数 = n − r（Buckingham π）。
4. 求幂次零空间得 π 乘子；把结论写成 π 之间的关系式。
5. 用 `scripts/dimension_check.py --pi` 复核 n、r、π 数；
   用 `--equation` 校验推导各步量纲一致。

## 校验规则（硬）

- 加减项必须同量纲；等式两侧必须同量纲。
- 超越函数参数必须无量纲。
- 单位制全程统一（SI 或显式自然单位制）。
