# 证明链模板

复制填写后运行 `python scripts/proof_chain_check.py --proof <本文件>`。

```
# 证明链

策略：S4 数学归纳（理由：目标对 n 递归；弃 S2：否定式不可形式化）

前提清单
H1 p 为奇素数
H2 a_1 = 1

P1 陈述：a_1 = 1。 依据：H2
P2 陈述：设 n = k 成立可推 n = k+1。 依据：P1 + H1 + 引理L1

引理L1 陈述：奇素数 p ≥ 3。 证明：p 为素数且 p ≠ 2，故 p ≥ 3（当轮证明）。

结论
G1 在 H1、H2 下成立。适用范围：p 为奇素数；p = 2 时失效。
```

## 要求

1. 步骤编号连续 `P1、P2…`，每步必带「依据：」，依据只能是
   定义/假设编号/引理编号/可核对定理/前序步骤。
2. 每条引理单独成块并给证明或真实出处（禁止「众所周知」）。
3. 前提清单中的每条假设须被至少一步使用，否则说明可否删除。
4. 结论段必须点名目标命题编号（G1）。
5. 全文禁止跳步词：显然、易见、同理可得、易证、略去、不难验证。
