# 量纲表模板

`dimension_check.py` 的输入格式：键＝符号，值＝基本量幂次向量（顺序与 `--bases` 一致）。

```json
{
  "m": [1, 0, 0],
  "a": [0, 1, -2],
  "F": [1, 1, -2],
  "k": [1, 0, -2],
  "x": [0, 1, 0]
}
```

基本量顺序：`--bases M,L,T`（可扩展 `M,L,T,Θ,I,N`）。

## 校验命令

```
python scripts/dimension_check.py --equation "m*a = F - k*x" --dims dims.json --bases M,L,T --pi
```

- 等式各加项量纲必须相同，两侧首项量纲必须相同；
- `--pi` 输出独立无量纲乘子个数 = 变量数 − 量纲矩阵秩（Buckingham π）；
- 超越函数（exp/log/sin/cos/tan）的参数必须无量纲，脚本会提示核验。

## 常见量纲

| 量 | M,L,T |
|---|---|
| 速度 v | [0,1,-1] |
| 加速度 a | [0,1,-2] |
| 力 F | [1,1,-2] |
| 能量 E | [2,1,-2] |
| 功率 P | [2,1,-3] |
| 弹簧刚度 k | [1,0,-2] |
| 粘度 μ | [1,-1,-1] |
