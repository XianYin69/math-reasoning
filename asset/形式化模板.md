# 形式化模板

复制本文件填写，然后运行 `python scripts/formalize_check.py --spec <本文件>`。

```
对象：`a_n` 为整数序列，`p` 为素数
假设：H1 `p` 为奇素数；H2 `a_1 = 1`
记号：`a_n` 第 n 项；求和范围 1..n；`|x|` 绝对值
目标：G1 证明 `a_n` 被 `p` 整除（取 n = p）
```

## 填写要求

1. 四段标题（对象/假设/记号/目标）各占一行，不得合并。
2. 假设逐条编号 `H1、H2…`；目标编号 `G1`（多个目标写 G1、G2…）。
3. 目标段出现的每个符号，必须在对象段或记号段先定义。
4. 禁止「显然/易见/同理可得/略/大概」等模糊措辞。
5. 物理题在记号段声明单位制（SI 或 ħ=c=1）与基本量顺序（M,L,T,…）。
