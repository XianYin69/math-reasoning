# 猜想记录模板

```
C1 陈述：对任意奇素数 p，a_p ≡ 0 (mod p)
  支持证据：特例 E1(p=3)、E2(p=5)、E3(p=7)；类比 A1（多项式系数版本）
  成立条件：p 为奇素数，且序列满足 H2 初值
  失败边界：p = 2 时 a_2 = 1 ≠ 0；初值改变后模式消失
  反例排查：counterexample_search.py --grid "p=3..97" → 网格内无反例
  状态：猜想（未证）
```

## 要求

1. 「支持证据」只写当轮算出的特例编号，不得引用未验证的他人结论。
2. 「成立条件」与「失败边界」缺一即视为记录不合格。
3. 状态只允许 `猜想 / 待验 / 已证`；升级为 `已证` 必须指向完整证明链文件。
4. 反例排查结果须原样粘贴（含命令与网格范围）。
